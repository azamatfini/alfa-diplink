Тестирование Android App Links для Сбера

Фокусируемся на рабочей схеме: android-app://

1. Базовые ссылки Android App

android-app://ru.sberbankmobile/transfers/overseas
android-app://ru.sberbankmobile/payments/p2p

2. С параметрами через путь

android-app://ru.sberbankmobile/transfers/overseas/UZ
android-app://ru.sberbankmobile/transfers/overseas/UZ/ASACUZ22

3. С параметрами через query string

android-app://ru.sberbankmobile/transfers/overseas?country=UZ
android-app://ru.sberbankmobile/transfers/overseas?country=UZ&phone=998381916876
android-app://ru.sberbankmobile/transfers/overseas?recipientCountry=UZ&recipientBank=ASACUZ22&phoneNumber=998381916876&amount=1000

4. Альтернативные форматы параметров

android-app://ru.sberbankmobile/transfers/overseas?recipient%3Acountry=UZ
android-app://ru.sberbankmobile/transfers/overseas?data=country:UZ;bank:ASACUZ22;phone:998381916876

5. Intent с android-app схемой

intent://ru.sberbankmobile/transfers/overseas?country=UZ#Intent;scheme=android-app;package=ru.sberbankmobile;end

Инструкция:

  • Нажимайте на кнопки по порядку
  • Записывайте, какие ссылки открывают Сбер
  • Отмечайте, какие параметры подставляются
  • Если приложение открывается на главный экран - параметры не работают
  • Если открывается на экран перевода - тестируйте дальше
