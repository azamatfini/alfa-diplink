Глубокий анализ новых вводных

Анализ информации от коллег:

  • androidapp://{application_id}/transfers/overseas/foreignbank
  • androidapp://{application_id}/androidapp/{application_id}/transfers/overseas/foreignbank
  • Тег: <a rel="alternate" href="...">Сбербанк перевод в зарубежный банк на карту по номеру телефона</a>

Ключевые моменты:

  • Используется androidapp:// (без дефиса)
  • Двойной путь с повторением application_id
  • Тег rel="alternate" - обычно для App Links/Universal Links
  • Конкретное описание действия

1. Точное повторение формата коллег

androidapp://ru.sberbankmobile/transfers/overseas/foreignbank
androidapp://ru.sberbankmobile/androidapp/ru.sberbankmobile/transfers/overseas/foreignbank
androidapp://ru.sberbankmobile/androidapp/ru.sberbankmobile/transfers/overseas/foreignbank/UZ

2. Анализ тега alternate - возможно это Web Intent

intent://ru.sberbankmobile/transfers/overseas/foreignbank#Intent;scheme=androidapp;package=ru.sberbankmobile;end
intent://ru.sberbankmobile/androidapp/ru.sberbankmobile/transfers/overseas/foreignbank#Intent;scheme=androidapp;package=ru.sberbankmobile;end
intent://ru.sberbankmobile/transfers/overseas/foreignbank/UZ#Intent;scheme=androidapp;package=ru.sberbankmobile;end

3. Параметры как часть пути (гипотеза: порядок имеет значение)

androidapp://ru.sberbankmobile/transfers/overseas/foreignbank/country/UZ
androidapp://ru.sberbankmobile/transfers/overseas/foreignbank/UZ/phone/998381916876
androidapp://ru.sberbankmobile/transfers/overseas/foreignbank/UZ/bank/ASACUZ22/phone/998381916876

4. Альтернативные package names

androidapp://com.sberbank.android/transfers/overseas/foreignbank
androidapp://sberbank.android/transfers/overseas/foreignbank
androidapp://sb.analytics/transfers/overseas/foreignbank

5. Специальные форматы с параметрами в EXTRA

intent:#Intent;launchFlags=0x10000000;component=ru.sberbankmobile/.ui.transfers.overseas.OverseasTransferActivity;S.country=UZ;end
intent:#Intent;launchFlags=0x10000000;component=ru.sberbankmobile/.ui.transfers.overseas.OverseasTransferActivity;S.country=UZ;S.phone=998381916876;S.bank=ASACUZ22;end

6. Web App Links (гипотеза: это веб-интерфейс)

https://online.sberbank.ru/transfers/overseas/foreignbank
https://sberbank.ru/androidapp/ru.sberbankmobile/transfers/overseas/foreignbank

Новые гипотезы для тестирования:

Гипотеза A: Формат androidapp:// требует специальной обработки на стороне приложения и может работать только в определенном контексте (например, из другого приложения Сбера).

Гипотеза B: Тег rel="alternate" указывает на то, что это App Link, который должен обрабатываться автоматически системой при переходе по соответствующему HTTP URL.

Гипотеза C: Возможно, нужен специальный intent с флагами и компонентом, а не просто URL.

Гипотеза D: Может требоваться подписанный intent или специальные разрешения.

Если ничего не сработает - радикальные варианты:

  1. Спросить у коллег рабочий пример - возможно у них есть реально работающая ссылка
  2. Проанализировать APK приложения Сбера - найти декларированные intent filters
  3. Использовать ADB для эмуляции intent'ов:
    adb shell am start -a android.intent.action.VIEW -d "androidapp://ru.sberbankmobile/transfers/overseas/foreignbank"
  4. Написать простое приложение-обертку которое будет эмулировать нужный intent
