Поиск правильного формата параметров для Сбера

1. Параметры как в веб-версии (закодированные)

android-app://ru.sberbankmobile/transfers/overseas?recipient%3Acountry=UZ
android-app://ru.sberbankmobile/transfers/overseas?recipient%3Acountry=UZ&recipient%3Abank=ASACUZ22

2. Параметры без кодирования (опасно, но возможно)

android-app://ru.sberbankmobile/transfers/overseas?recipient:country=UZ
android-app://ru.sberbankmobile/transfers/overseas?recipient:country=UZ&recipient:bank=ASACUZ22

3. Альтернативные названия параметров

android-app://ru.sberbankmobile/transfers/overseas?country=UZ
android-app://ru.sberbankmobile/transfers/overseas?countryCode=UZ
android-app://ru.sberbankmobile/transfers/overseas?destinationCountry=UZ

4. Параметры в формате JSON

android-app://ru.sberbankmobile/transfers/overseas?params={"country":"UZ"}
android-app://ru.sberbankmobile/transfers/overseas?data={"country":"UZ","bank":"ASACUZ22","phone":"998381916876"}

5. Параметры через Intent (специальный формат)

intent://ru.sberbankmobile/transfers/overseas?S.country=UZ#Intent;scheme=android-app;package=ru.sberbankmobile;end
intent://ru.sberbankmobile/transfers/overseas?S.recipientCountry=UZ#Intent;scheme=android-app;package=ru.sberbankmobile;end

6. Параметры как фрагмент URL

android-app://ru.sberbankmobile/transfers/overseas#country=UZ
android-app://ru.sberbankmobile/transfers/overseas#recipient:country=UZ
