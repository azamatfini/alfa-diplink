Альтернативные подходы

1. Официальные Universal Links (App Links)

https://online.sberbank.ru/transfers/overseas
https://www.sberbank.ru/retail/transfers/foreign

2. Прямой вызов Activity (только Android)

intent:#Intent;component=ru.sberbankmobile/.ui.transfers.overseas.OverseasTransferActivity;end
intent:#Intent;component=ru.sberbankmobile/.ui.transfers.overseas.OverseasTransferActivity;S.country=UZ;end

3. Специальные схемы для конкретных банков

sberbankonline://transfer/to/bank/ASACUZ22
sberbankonline://international/transfer/UZ

4. Резервный вариант - веб-версия с параметрами

https://online.sberbank.ru/transfers/overseas?country=UZ&phone=998381916876
https://online.sberbank.ru/CSAFront/transfer/overseas.do?country=UZ

Проблема: Все deeplink'ы возвращают "по ссылке ничего не нашлось"

Возможные причины:

  • СберБанк отключил поддержку deeplink'ов для международных переводов
  • Требуется специальная аутентификация
  • Параметры должны передаваться в другом формате (не через URL)
  • Нужны специальные права или подпись приложения

Рекомендации:

  1. Обратиться в поддержку Сбера - спросить о поддержке deeplink'ов
  2. Использовать веб-версию с предзаполненными параметрами
  3. Рассмотреть альтернативные банки которые лучше поддерживают deeplink'и
  4. Создать свое приложение-прослойку которое будет открывать Сбер с нужными параметрами

К сожалению, без доступа к внутренней документации Сбера или работающим примерам, дальнейшие попытки могут быть бесполезны.
